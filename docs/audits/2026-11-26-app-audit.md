# App audit, 2026-11-26 (0.1.37)

27 Sonnet reviewers read the app (10 areas, each for bugs and for flow, and 7 user journeys end to end);
240 raw findings were merged into 98, and two more reviewers tried to refute each one against the code
(one checking the code, one the user impact). 72 were upheld by both (**confirmed**), 20 by one
(**plausible**), 6 refuted (listed at the end). Severity is the verifiers' own. Line numbers are as of
commit 57caca8. Workflow run wf_5b55ba16-6f8.

## A. Rough edges in what 0.1.37 added (fix first)

### F1. Estimate intent (auto-sent when a place sheet is open and phase becomes IDLE) clears the End undo window, so Undo does nothing

*medium · bug · confirmed* — `android/nav/session/src/main/kotlin/io/github/spysyweeb/beamline/nav/SessionCore.kt:346-350; android/app/src/main/kotlin/io/github/spysyweeb/beamline/app/ui/AppRoot.kt:191-194; android/app/src/main/kotlin/io/github/spysyweeb/beamline/app/ui/AppFlows.kt:645-649,729-733`

**What happens:** While guiding with a place sheet open, or after tapping any POI within the Trip ended window, the user ends the trip. The app auto-sends NavIntent.Estimate, which clears `ended`. Undo then does nothing and 'Continuing the trip...' shows until CONTINUING_CAP_MS with no explanation.

**Fix:** Do not clear `ended` for read-only/passive intents (Estimate, IDLE-only SetRouteType/SetOptions), or skip Estimate while tripEnded != null. Report undo failure to the UI so 'Continuing' ends.

### F2. Start/option/stop-limit failures and route warnings are invisible at the Peek and Middle route-sheet heights

*medium · bug · confirmed* — `android/feature/drive/src/main/kotlin/io/github/spysyweeb/beamline/feature/drive/RouteSheet.kt:100-158,160-183,313-327,508-521; android/nav/session/src/main/kotlin/io/github/spysyweeb/beamline/nav/SessionCore.kt:952-1003,502-504; android/feature/drive/src/main/kotlin/io/github/spysyweeb/beamline/feature/drive/Presentation.kt:124`

**What happens:** The sheet opens at MIDDLE. Start can set a problem (PACKS_BUSY, ENGINE failure, TOO_MANY_STOPS, option replan failure) while cards remain; nothing shows and Start re-enables. Route warnings (far-snapped stop, 'no route avoids tolls') and toll/highway notes are only drawn at FULL, so users start without seeing them.

**Fix:** Show problem (with Retry when canRetry) and at least the first warning above Start at every height, plus a toll chip on LowRouteCard. Consider raising the sheet or a snackbar when a problem is set.

### F3. Dead ends at Middle/Peek height: 'No GPS / outside maps' text points to controls that only exist at FULL, and there is no Cancel; no planning indicator

*medium · flow · confirmed* — `android/feature/drive/src/main/kotlin/io/github/spysyweeb/beamline/feature/drive/RouteSheet.kt:81-98,141-158,212-350; android/nav/session/src/main/kotlin/io/github/spysyweeb/beamline/nav/SessionCore.kt:1848; android/feature/drive/src/main/kotlin/io/github/spysyweeb/beamline/feature/drive/Overlay.kt:297`

**What happens:** With no GPS the middle sheet says 'Choose a start point or try again' above a disabled Start, but From row, Retry and Cancel exist only at FULL. The middle height also shows no destination, options, stops, Swap or Cancel, and while planning shows only a thin progress line and greyed Start with no text or TalkBack announcement.

**Fix:** Put the problem's action beside its text at every height, add a Cancel X and destination header at MIDDLE, show 'Finding routes...' with a live region while busy.

### F7. Silent self-update on leaving the app kills active downloads/installs and ignores planned trips and non-guiding phases

*medium · flow · confirmed* — `app/src/main/kotlin/io/github/spysyweeb/beamline/app/MainActivity.kt:232-245; app/src/main/kotlin/io/github/spysyweeb/beamline/app/AppGraph.kt:510; app/src/main/kotlin/io/github/spysyweeb/beamline/app/update/AppUpdates.kt:102-150`

**What happens:** With an update Ready, pressing Home during a pack download/install, a route preview (PLANNING/CHOOSING), the resume offer or the arrival card triggers a silent install that restarts the process. ### F20. Outgoing screens blank out during the slide-out because they read live state already cleared

### F26. Drive-time Estimate: no retry when no fix, route type/options differ from the real trip, stale cache, stale queued estimates block the single routing thread
