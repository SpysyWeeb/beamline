# Play test, 2026-11-26 (0.1.39)

Sonnet testers used the app the way a person does, on three emulators (lanes a, g, i), through
screenshots and the on-screen element list: tap, drag, type, rotate, move the GPS, force-stop, slow
animations, large text. Eight missions: first run and the Pennsylvania download, a simulated drive, the
map, search, interruptions, settings, planning a trip, States plus accessibility. Online features
stayed off; nothing was sent. 75 findings were merged into 64, and a fresh tester tried to reproduce
each one on an emulator: **34 reproduced, 22 partly, 8 not** (the 8 are listed at the end). Severity
is the reproducing tester's. `F<n>` is the matching finding of the code audit
(`2026-11-26-app-audit.md`). Screenshot names refer to the run's scratch folder (not kept in the
repo). Workflow run wf_b5314893-3bc, 73 agents, about 1 h 50 min.
